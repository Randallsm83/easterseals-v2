# Triage labels

| Canonical role | Tracker label | Meaning |
|---|---|---|
| needs-triage | needs-triage | Maintainer evaluation needed |
| needs-info | needs-info | Waiting for reporter information |
| ready-for-agent | ready-for-agent | Fully specified; ready for autonomous implementation |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Use this mapping whenever a skill names a triage role.
This file defines vocabulary; it does not prove a label already exists remotely.
